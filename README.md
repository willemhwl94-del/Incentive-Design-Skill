# Incentive Design Skill

Reusable Codex skill and component library for designing and building mobile-first incentive activity pages.

This repository contains:

- Campaign skill contracts and orchestration docs
- Reusable H5 component contracts and runtime components
- Page structure references for incentive campaign flows
- Visual style references and QA checklists
- Curated examples and fixtures

The default target output is H5 activity pages under `/Users/bytedance/Documents/Incentive Page Cases/{case-name}/`.
